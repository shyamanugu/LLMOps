# ── Python 3.14 note ────────────────────────────────────────────────────────
# These are version *floors* (>=), not exact pins, so pip can pick a wheel that
# matches your interpreter — including Python 3.14 where wheels exist. Several of
# these are compiled (numpy, pyarrow, duckdb, polars, pydantic-core, cryptography);
# if a cp314 wheel is not yet published for one of them, pip would fall back to a
# source build and fail. In that case use Python 3.12 for the full real pipeline
# (matches the Dockerfile) — the DEMO still runs on 3.14 with zero installs.
#
# pyodbc is intentionally NOT here — it is only needed for the Azure SQL steps
# (individual_metrics, kpi) and is the hardest to build. Install it separately
# with requirements-sql.txt when you need those steps.
