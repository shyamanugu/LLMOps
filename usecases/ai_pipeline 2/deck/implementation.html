Platform → AI Pipeline (APIX)

The AI Pipeline is a batch call-analytics application: it turns raw contact-centre transcripts into per-agent coaching intelligence. We used it as the first proof point — wiring the LLMOps platform into a real, working app to prove reuse.

Key implementation decisions we already made

Thin adapter, not a rewrite

We wrapped the single LLM seam instead of re-platforming the pipeline. Low risk, fully reversible, and each capability shipped independently.

Fail-open everywhere

If the platform is absent or a cloud service is down, the pipeline still runs — observability/guardrails degrade to no-ops rather than breaking a batch.

PII flagged, not blocked

Transcripts legitimately contain customer PII; blocking would silently drop calls. We flag for audit and block genuine secret leaks — a policy you can change in one file.

Honest status

Everything above is demonstrated in mock mode (local data, deterministic mock model) so it runs anywhere with zero setup. The real path (live Azure OpenAI, Storage, SQL, Monitor) is built and one env-flag away, pending the decisions on the next page.
